## Scripts

| Comando | Qué hace |
| --- | --- |
| `npm run dev` | Ejecuta `src/index.ts` en modo watch. |
| `npm run build` | Compila TypeScript a `dist/`. |
| `npm start` | Ejecuta la build compilada. |
| `npm run typecheck` | Comprueba tipos sin generar salida. |
